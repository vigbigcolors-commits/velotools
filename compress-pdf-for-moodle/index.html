Moodle PDF size FAQ

Moodle says the file is bigger than the maximum size allowed. How do I compress it?
Use this page, download the result, and upload again. Check the assignment’s listed maximum — your school may use a number other than 10 MB.
Where do I find my course’s real size limit?
Open the assignment settings text or ask the teacher/admin for maxbytes. Our 10 MB checker is a safe default, not a live feed from Moodle.
I have colored plots — will they survive?
Yes. This Moodle URL keeps color. Blackboard’s page on this site is the one that forces grayscale for scan-heavy homework.
Can I batch a whole folder for one week’s labs?
You can compress several PDFs in one sitting, but Moodle still enforces each activity’s rules. Check every output against the size warning.
Is my gradebook data involved?
No. There is no Moodle login and no server sync — only a local PDF shrink.
