Security: images never leave the tab

VeloTools JPG to PDF reads each file with the File API, optionally rasterizes PNG/WebP to JPEG on a canvas, then embeds streams with pdf-lib. No fetch carries image bytes to a server — the download is a local Blob.

How to convert JPG to PDF in 3 steps

  1. Drop one or more images (JPG, PNG, WebP) into the upload zone.
  2. Drag rows to set page order; choose page size and margin.
  3. Click Create PDF, then download — ready for print or email.

Fit vs fixed page size

Fit creates one page per image at the image’s pixel dimensions (converted to PDF points). Ideal for scans you want 1:1. A4 / Letter centers each image on a standard page with your chosen margin — better for printing mixed phone photos.

Need the reverse direction? Use PDF to JPG. To shrink the result afterward, open Compress PDF.

Frequently asked questions

Can I convert multiple JPGs into one PDF?
Yes — up to 40 images. List order equals page order.
Are images uploaded?
No. Processing is 100% client-side.
Do PNG and WebP work?
Yes. They are drawn to canvas and saved as JPEG inside the PDF for broad reader compatibility.
What page sizes are supported?
Fit to image, A4, and US Letter, with optional margins.
