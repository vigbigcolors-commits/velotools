Why process PDFs in the browser?

Cloud converters require uploading contracts, invoices, and ID scans to someone else’s storage. VeloTools PDF tools use the same architecture as our image compressor: the page loads once, then pdf-lib, PDF.js, and the Canvas API run inside your tab. Closing the tab clears the working copy.

How to use this hub

  1. Choose the job — organize, shrink, convert, or secure.
  2. Open the tool card; drop files into the zone on that page.
  3. Download the result. Nothing was uploaded for processing.

What we ship today vs later

Every card above is a finished tool. Office formats (Word, Excel, PowerPoint) and full in-document text editing need engines that cannot meet our zero-upload quality bar yet — they stay off this grid until they can.

Frequently asked questions

Do VeloTools PDF tools upload my files?
No. File bytes stay in browser memory. Network requests after page load are for static assets only — not your documents.
Which PDF tools are free?
All eight on this hub: Merge, Split, Rotate, Compress, PDF to JPG, JPG to PDF, Unlock, and Protect. No account, no watermark.
Is Protect PDF encryption real?
Yes. The downloaded file includes a Standard Security Handler dictionary. Opening it in a PDF reader requires the password you set.
Will offline mode work?
After scripts load (or from cache), merge, split, rotate, and similar tools keep working without a network. First visit still needs CDN libraries.
