Security: encryption without upload

Your password is typed into this page and used only to derive the PDF encryption key in memory. The output file includes a Standard Security Handler /Encrypt dictionary. Neither the password nor the PDF body is posted to VeloTools servers.

How to protect a PDF in 3 steps

  1. Drop an unprotected PDF into the upload zone.
  2. Enter and confirm an open password (at least 4 characters).
  3. Click Protect PDF and download — open it in any reader to verify the password prompt.

Open password vs owner password

Protect sets a user (open) password so viewers must unlock the file before reading. The same string is also used as the owner password unless you later expand the UI — enough for “share only with people who know the secret.” Permission flags disable easy modify/copy while still allowing print and accessibility extraction.

To remove protection later, use Unlock PDF with the same password.

Frequently asked questions

Is Protect PDF encryption real?
Yes. The file requires your password in Acrobat, Preview, Chrome, and other standard readers.
Does my password leave the device?
No — it is used only locally during encryption.
Already locked PDF?
Unlock first, then protect with a new password.
How do I remove the password?
Open Unlock PDF and enter the password.
