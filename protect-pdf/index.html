PDF permissions

Defaults restrict copy and edit. Printing and form fill stay on unless you change them. Readers that respect PDF security will enforce these after the open password.

Security: encryption without upload

Your password is typed into this page and used only to derive the PDF encryption key in memory. The output file includes a Standard Security Handler /Encrypt dictionary. Neither the password nor the PDF body is posted to VeloTools servers.

How to protect a PDF in 3 steps

  1. Drop an unprotected PDF into the upload zone.
  2. Enter and confirm an open password (at least 4 characters). Adjust PDF permissions if needed.
  3. Click Protect PDF and download — open it in any reader to verify the password prompt.

Open password vs owner password

Protect sets a user (open) password so viewers must unlock the file before reading. A separate owner password is generated in the browser for permission enforcement and is never shown or stored — you only need the open password to view the file. Use the permission checkboxes to allow or deny print, copy, edit, and form fill.

To remove protection later, use Unlock PDF with the same open password.
