## Шаг за шагом (ссылки)

### 1) Войти
https://www.producthunt.com/  

Личный аккаунт (не company). Тот же, с которым Oneirox — ок.

### 2) Начать пост
Справа сверху: **Submit** → **New Product**  
Или напрямую начни с URL продукта в форме submit (интерфейс PH иногда меняется).

Официально: https://www.producthunt.com/launch/preparing-for-launch  

### 3) URL продукта
```
https://velotools.app/
```
Без UTM, без bit.ly.

### 4) Заполнить тексты (готовые)

**Name**
```
VeloTools
```

**Tagline** (коротко, ~60 символов)
```
Browser tools that never upload your files
```

**Description** (честно)
```
VeloTools is a free suite of browser utilities: image compress, PDF tools, invoices, QR codes, background remover, and Focus Room.

Everything runs in your browser (Canvas / WebAssembly). Your files are not uploaded to our servers. No account required.

Built for people who need real tools without giving up document privacy.
```

**Topics** (выбери близкие)
- Productivity  
- Privacy  
- Developer Tools  
- Design Tools  
- Chrome Extensions *(только если реально есть; иначе не ставь)*  
- Artificial Intelligence *(только если честно про BG remover AI — можно)*

Лучший набор без вранья: **Productivity, Privacy, Design Tools** (+ Developer Tools по желанию).
